# DMIT 补货通知：库存为什么总在几分钟内清空，Pro/EB/T1 全套餐价格与抢货思路一次讲透

搜 "DMIT 补货通知" 的人，多半不是第一次来。你已经知道这家机房线路好、也知道它经常没货，只是想知道这一次到底补了什么、还剩下什么、值不值得现在动手。

所以这篇不绕弯：先把 DMIT 一直缺货的真实原因讲清楚，再把当前在售的洛杉矶、香港、东京套餐整理成表，最后说几个下单前容易踩的细节。

## 为什么 DMIT 的货总是"刚看到就没了"

DMIT 的库存问题不是营销手段，是硬件和 IP 两头的物理限制叠加出来的。

先看 IP。DMIT 所有机房用的 IPv4 地址段长期处于紧张状态，新买的地址要走合同过户流程，什么时候交割到位官方也给不出准确时间。有跟踪站点整理的官方公告提到，DMIT 为了缓解缺货，甚至打破了自己过去 3 到 6 个月的 IP 预热惯例，新 IP 一到手就直接投入资源池。

再看洛杉矶机房。LAX 是 DMIT 的核心腹地，Pro 系列几乎全靠这里。今年 5 月 DMIT 一度暂停全线销售，官方给出的理由是机柜空间、电力供应和存储集群三样都没排到期——服务器硬件明明已经运到机房了，但没有机位和动力电就上不了架。这种情况不是砸钱就能立刻解决的，数据中心排期本身就是个慢活。

还有一个背景很多人不知道：DMIT 把已经"退休"的上一代 AS3 平台（AMD EPYC 7003 系列）重新上架了，同时上调了 AN4、AN5 两代新平台的机型价格。换句话说，现在能买到的 LAX 机器里，AS3 是性价比那一档，AN5 是性能顶配但更贵的那一档。V2EX 上有用户直接形容这是"应对机荒"的操作。

理解了这三件事，你就能看懂为什么"补货通知"这四个字在 DMIT 用户群里这么有分量：它补货的频率不高，每次放出来的量也不算多，而且当前这批卖完之后下一次是什么时候，官方自己都没给时间表。

## 这一轮补货补了什么

从这一年的补货节奏看，DMIT 洛杉矶 LAX 的 AS3 系列是补货主力，Pro、Eyeball（EB）、T1 三条产品线基本是先后或同时上架。

最近的几轮补货有两个共同特征：

- **走正价，不打折促销。** 缺货期间不抬价也不放特价，直接按原价补货，对老用户来说算是个明确信号——硬件和 IP 资源确实到位了。
- **不是所有线都能买到。** 有些轮次 EB 系列会单独缺货，只放 Pro 和 T1。所以看到"补货通知"别默认全都有，得点进购物车看具体哪一款还挂着 "Out of Stock"。

另外要提醒一句：官方对 LAX AS3 平台有明确说明，这个平台目前仍处于持续优化阶段，磁盘性能和 SLA 可能低于成熟平台。介意的用户建议先测试再部署正式业务。

## 怎么第一时间收到补货通知

官方没有"到货提醒"这种按钮，最可靠的做法还是把购物车页当成信息源。

**第一层：官网购物车页。** 这是唯一的权威来源。第三方站点写的"已补货"永远有延迟，也可能只补了部分机型。养成习惯：看到任何补货消息，第一件事是打开购物车页确认目标机型是真有货还是还灰着。

**第二层：库存监控页。** 有站长自建了 DMIT 专用库存监控，也有覆盖多家商家的通用补货监控站。这类页面的作用是替你定时刷新，有货就提醒，省得手动刷。但要注意它们只反映抓取那一刻的状态，不能当成下单依据。

**第三层：社区帖子。** V2EX 和 linux.do 上的补货帖往往比搜索引擎收录得快，而且下面常有"哪几款还有货""这次是不是正价"的一手反馈。缺点是信息噪音大，也经常有人顺手推自己的 AFF。

还有一点值得知道：DMIT 的补货经常集中在某几天内分批发。有人观察到官方会先把最新一批硬件一次性上架，卖完再等下一批。所以如果你看到社区里说"补了"，但自己打开没货，别急着判断是假消息——可能已经被清空了，也可能只是你搜的那一款没放。

## 抢之前先想清楚：Pro、EB、T1 怎么选

补货时最容易犯的错，不是手慢，是抢完了才发现买错线路。

**电信用户、对回国体验有硬要求** → 选 Pro。三网回程 CN2 GIA，晚高峰波动小，这也是 DMIT 最被认可的一条线。代价是同价位下流量给得紧。

**联通、移动用户为主，或者想要流量宽一点** → 选 EB。电信回程 9929、移动回程 CMIN2，都是各家拿得出手的优质线路，价格和 Pro 同档但流量多出一截。

**只做海外业务、落地、中转、备份** → 选 T1。别指望它回国快，但它带宽大、超量后能保持 100Mbps 以上，年付还能压到 $36.90。

一句话判断法：**先确定你的用户在哪，再确定你主用哪个运营商，最后才看配置。**

配置上，1 核 2GB 跑个人博客、小型 WordPress、面板、监控都够用。真正需要往上加档的一般是两类情况：单站流量大到月耗超 1TB，或者要跑数据库、CI、视频转码这类吃 CPU 和 IO 的活。

## 下单前值得留意的几个细节

**付款方式。** DMIT 支持支付宝、微信支付、PayPal 和信用卡。用支付宝下单的话，如果开机后测试不满意，整个流程会轻松一些，不用走跨境争议。

**免费换 IP 有条件。** LAX Pro 和 EB 在符合条件时可以免费更换 IPv4，几个门槛是：实例开通满 7 天、距上次换 IP 至少 15 天、ICMP 和 TCP 全端口都不可达、剩余服务期不少于 7 天。IP 被墙是很多人的真实痛点，这个政策值得先看明白，别等出问题才翻条款。

**流量是双向算的。** 高流量业务要特别留意这一点，别按单向估。

**优惠码别乱填。** DMIT 的优惠码是按产品线和付款周期分的，而且经常轮换。像是针对 LAX EB 非月付的循环 8 折码、香港 EB 年付的循环 85 折码、Standard（原 Lite）系列的 `Lite-Annually-Recur-30OFF` 年付 7 折码，都在不同来源里被提及过，但并不保证此刻仍然有效。老规矩：结算页填进去点验证，能减就是能用，不能减就换一个，别为了省钱去信来源不明的码。

**别为了囤货下单。** 补货通知天然带一点"再不买就没了"的紧迫感，但如果你手上根本没有要用它的项目，年付的钱就是白交。真的需要一台机器放博客、跑代理或者做中转，再动手。

## 几个高频问题

**补货通知会发到邮箱吗？**
官方层面没有面向所有用户的到货订阅。社区里流传的做法是用第三方库存监控加邮件提醒，或者干脆自己写脚本定时抓购物车页。也可以直接把页面存成书签，每天顺手刷一次。

**AS3 是不是很老的平台，值得买吗？**
AS3 用的是 AMD EPYC 7003 系列，比 AN4、AN5 落后一代，但性能放今天依然够用，而且内存、硬盘、流量给得比新平台同价位更多。代价是官方明确标注它仍在持续优化阶段，SLA 和磁盘性能可能有波动。轻量业务完全没问题，核心生产环境建议先测。

**为什么 Pro 和 EB 同价但配置差这么多？**
因为贵的是路由，不是硬件。Pro 的 CN2 GIA 回程成本高，同样的钱自然要在流量上让一点。这也是为什么"只看配置选线路"是错的。

**香港和洛杉矶该选哪个？**
距离决定延迟。你的用户在华南、需要 10–30ms 的响应，香港 Pro 是最优解，但价格是洛杉矶的好几倍。用户是全国分布的博客、外贸站或者中转节点，洛杉矶 Pro 的性价比明显更高。
